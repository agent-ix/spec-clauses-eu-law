# NFR-001: Preserve evidence provenance

## Statement

The synthetic system SHALL retain a source reference and an integrity digest for each evidence record.

## Measurement and Evaluation

The evidence record is inspected for both fields.

| Measure | Target | Verification |
|---|---|---|
| Source and digest fields | Both present | Test |

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| example.invalid/NFR-001-AC-1 | Every retained evidence record identifies its source and digest. | Test |

## Verification

Check the synthetic record for a source reference and an integrity digest.
