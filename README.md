# EU Law Compliance Pack

This repository provides a clause-only Quire module for selected MDR software
and IT-security requirements and MDCG cybersecurity guidance. Clause sets will
be added by the later authoring tickets.

Public sources may be named and cited. All summaries must use original wording. No harmonised or other paywalled standard may be named, numbered, quoted, or paraphrased.

See [spec/spec.md](spec/spec.md) for set designs, normative tables, the shared
output catalog, rights metadata and scope. The installable module name is
`spec_clauses_eu_law`.
