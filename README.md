# EU Law Compliance Pack

This repository holds the requirements for a clause-only quire module covering selected MDR software and IT-security requirements and MDCG cybersecurity guidance. Clause content and packaging are specified in later project tickets.

Public sources may be named and cited. All summaries must use original wording. No harmonised or other paywalled standard may be named, numbered, quoted, or paraphrased.

See [spec/spec.md](spec/spec.md) for the set designs, normative tables, shared output catalog, rights metadata and scope.
